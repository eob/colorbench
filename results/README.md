# Results

`colorbench_summary.json` is historical output from the earlier, invalid
100-image semantic prototype. It is preserved as history and is not published
as ColorBench 0.2.0 evidence.

Measured pilot runs live in `runs/`. Only runs verified by
`python -m baseline.finalize --run-dir <path> --verify` are publication sources.
Mock runs and partial unsealed runs are not benchmark results.
