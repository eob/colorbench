# ColorBench artwork

`social-card.html` is the editable HTML/SVG source for the 1200×630 share image.
Rebuild it with `bun run build:branding`. It uses the bundled DejaVu Sans font
and its license in `src/assets/`. The artwork is illustrative; it is not a
scored benchmark specimen. `colorbench-logo.svg` is the scalable standalone mark.
